# Screenshots Guide

Add these files here to complete the README:

| Filename | What to Capture |
|---|---|
| `01-chat-interface.png` | Full browser window — chat UI with sidebar, active conversation, intent tags, source citations |
| `02-itinerary.png` | Ask for a 2-day trip plan; sidebar showing active trip selector |
| `03-multilingual.png` | Switch language dropdown to Romanian or Russian, ask the same question |
| `04-sync-status.png` | Sidebar status panel after clicking "Smart Sync" |

**Tips:**
- Use 1400×900px browser window
- Zoom browser to 100%
- Dark/light system theme looks great — pick one and stay consistent
- On macOS: `Cmd+Shift+4` for region screenshot
- On Windows: `Win+Shift+S` for snip tool
